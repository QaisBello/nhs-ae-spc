## SPC Mean

*SPC* · table `Monthly` · format `0.0%` · Centre line: mean of the last 24 months. Blank outside the window so the chart draws it only there.

```dax
SPC Mean =

    CALCULATETABLE ( VALUES ( 'Calendar'[Month Index] ), REMOVEFILTERS ( 'Calendar' ), 'Calendar'[In SPC Window] = 1 )
VAR _points =
    ADDCOLUMNS (
        _months,
        "@v",
            VAR _i = 'Calendar'[Month Index]
            RETURN CALCULATE ( [% Within 4 Hours], REMOVEFILTERS ( 'Calendar' ), 'Calendar'[Month Index] = _i )
    )
VAR _mean = AVERAGEX ( _points, [@v] )
RETURN
    IF ( MAX ( 'Calendar'[In SPC Window] ) = 1, _mean )
```

## SPC Average Moving Range

*SPC* · table `Monthly` · format `0.00%` · Average month-to-month change. Moving ranges of 3.267 x the average or more are screened out and the average recalculated, as in Making Data Count.

```dax
SPC Average Moving Range =
VAR _months =
    CALCULATETABLE ( VALUES ( 'Calendar'[Month Index] ), REMOVEFILTERS ( 'Calendar' ), 'Calendar'[In SPC Window] = 1 )
VAR _points =
    ADDCOLUMNS (
        _months,
        "@v",
            VAR _i = 'Calendar'[Month Index]
            RETURN CALCULATE ( [% Within 4 Hours], REMOVEFILTERS ( 'Calendar' ), 'Calendar'[Month Index] = _i )
    )
VAR _first = MINX ( _points, 'Calendar'[Month Index] )
VAR _ranges =
    ADDCOLUMNS (
        FILTER ( _points, 'Calendar'[Month Index] > _first ),
        "@mr",
            VAR _i = 'Calendar'[Month Index]
            RETURN ABS ( [@v] - MAXX ( FILTER ( _points, 'Calendar'[Month Index] = _i - 1 ), [@v] ) )
    )
VAR _amr = AVERAGEX ( _ranges, [@mr] )
VAR _screened = AVERAGEX ( FILTER ( _ranges, [@mr] < 3.267 * _amr ), [@mr] )
RETURN
    IF ( MAX ( 'Calendar'[In SPC Window] ) = 1, COALESCE ( _screened, _amr ) )
```

## Assurance (DAX)

*SPC* · table `Monthly` · format `General` · Where the standard sits against the DAX process limits. Should agree with the Python assurance.

```dax
Assurance (DAX) =
VAR _upl = [SPC Upper Limit]
VAR _lpl = [SPC Lower Limit]
RETURN
    SWITCH (
        TRUE (),
        ISBLANK ( _upl ), BLANK (),
        [4-Hour Standard] > _upl, "Will consistently miss",
        [4-Hour Standard] < _lpl, "Will consistently meet",
        "Hit and miss"
    )
```
